WiFi requirements (check before installing)
  • 2.4 GHz network — the device cannot see 5 GHz
  • Normal password network (WPA2‑Personal). Not a login‑page "guest" network, not Enterprise (username + password)
  • Internet access on that network (no captive portal)

Install — in order

  1. Place it where it hears the room: at ear/table height, open to the space, not right next to a speaker and not inside a cabinet.
  2. Plug it in permanently (any USB‑C phone charger). It has no battery — it runs only while plugged in, so choose a spot near an outlet.
  3. First boot shows the setup network automatically. The screen displays SETUP — AutoVolume‑5798. On a phone, join the WiFi network AutoVolume‑5798 → a setup page opens (if not, browse to http://192.168.4.1) → pick the venue's 2.4 GHz network → enter its password → Save.
  4. Within ~30 seconds the screen shows WiFi Connected and Server Online. Done — it registers itself; nothing to type on the device.
  5. Switch on auto‑volume: log in to the dashboard with the code above and turn the zone toggle on (it ships switched off so nothing changes until you're ready). BMAsia can also switch it on remotely.

Day to day

  • Nothing to do — it listens to the room and adjusts the music on its own.
  • In the dashboard you can change Sensitivity, Reactivity and the volume range. Tap ? next to any setting for a plain explanation.
  • Pause it anytime with the zone toggle (e.g. for a private event).

If something looks off

  • Screen dark → check the USB‑C cable/charger; press PWR once to switch on.
  • "Server Offline" for more than 15 minutes → the device restarts itself automatically. If it stays offline, the venue WiFi has no internet — check that a phone on the same WiFi can open a website.
  • Manual restart: hold PWR (side button) for 6 seconds until the screen goes black, then press it once. Don't tap the screen while it starts.
  • WiFi changed? It re‑opens the setup network by itself when it can't find the saved WiFi — just repeat step 3.
